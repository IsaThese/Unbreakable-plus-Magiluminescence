# Unbreakable and Toggleable Magiluminescence

Don't Starve Together mod for Magiluminescence (`yellowamulet`).

## Features

- **Unbreakable** — durability still drains, but the amulet does **not disappear at 0%** (same idea as the original Unbreakable Magiluminescence mod / miner hat). Refuel with Nightmare Fuel to use it again.
- **Durability Loss** — if set to No, fuel is never consumed while active.
- **Toggleable** — while equipped, **Turn On / Turn Off** appears in the inventory action UI (same idea as the Magician's Top Hat)
  - On: light, bloom, and 20% speed boost (requires fuel)
  - Off: worn as an amulet only (sanity bonus still applies)

## Install

Copy this folder into your DST `mods` directory, then enable it when hosting a world:

`D:\SteamLibrary\steamapps\common\Don't Starve Together\mods\`

All clients need the mod (`all_clients_require_mod`) so the Turn On/Off action shows in the UI.
